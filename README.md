# Patient Dashboard

A responsive patient healthcare dashboard created from the provided
design reference.

## Features

- Patient dashboard UI
- Jessica Taylor patient data
- Patient profile information
- Diagnosis history
- Blood pressure history chart
- Respiratory rate
- Temperature
- Heart rate
- Diagnostic list
- Lab results
- Responsive desktop, tablet and mobile layouts

## Technologies

- HTML5
- CSS3
- JavaScript
- Chart.js
- REST API

## Running the Project

Open `index.html` in a browser.

The application retrieves patient information from the provided
patient data API and displays the data for Jessica Taylor.

## Notes

The dashboard is designed to reproduce the provided healthcare
dashboard design while using API-driven patient information.
